자동 성능 최적화
코드 입력 없이 ① 1280px 중심 필터 탐색 → ② 해상도 비교 → ③ 워커·가속 비교 순으로 진행합니다. 현재 설정을 포함해 필터 최대 8개·해상도 추가 2개·실행 설정 최대 5개를 비교하며, 선택한 검사 단계와 글자 크기 범위는 유지합니다.


먼저 카메라를 촬영하거나 사진·테스트 이미지를 준비하세요.
서로 다른 입력 2개 이상에서 같은 위치·코드가 일치하면 비교 기준으로 사용합니다. 한 조건에서만 발견된 위치는 누락 기준에서 제외합니다.
필터·해상도 탐색은 각 1회이며 시간으로 순위를 정하지 않습니다. 실행 설정만 준비 1회 후 측정 1회로 비교합니다. 기준 코드 보존 → 미확정 위치 누락 감소 → 충돌·확인 필요 감소 → 측정 시간 순으로 선택합니다. 워커·가속만 바꾼 결과는 교차 일치 표에 추가하지 않습니다.
교차 일치는 정답이나 정확도 보장이 아닙니다. 근거 부족·기존 기준 코드 손실 시 설정을 유지합니다. 생성 테스트 이미지는 입력 없이 생성 코드를 기준으로 오인식을 비교합니다. 추천값은 현재 이미지·기기 기준입니다.

고급 설정








현재 원본 이미지에서 영문·숫자 한 글자의 높이 기준입니다. 자동은 인식된 코드 크기로 범위를 계산합니다. 수동 범위 밖의 결과는 제외하며, OCR 연산량을 줄이는 설정은 아닙니다. 분할 확대 좌표는 원본 크기로 환산합니다. 단계별 발견 수는 크기 필터 적용 전이며 최종 개수는 적용 후입니다.
최근 크기 범위: 인식 후 표시

막대 바깥 높이는 최대, 중앙의 진한 띠 높이는 최소 크기입니다. 원본 픽셀을 화면 배율로 환산하며 인식 영역을 제한하지 않습니다. 자동 범위는 인식 후 표시합니다.


노이즈·밝기·대비·인쇄물 흐림을 WebGL2로 처리합니다. 초기 준비와 픽셀 전송 비용이 있으며 이진화·표선·작은 영역 제거는 CPU가 처리합니다. 미지원·오류 시 CPU로 전환합니다.
최근 경로: 인식 후 표시 · 실제 GPU 선택은 브라우저가 결정합니다.

촬영 전 빨간 점 검사입니다. 끄면 미리보기만 유지합니다. 촬영 후 인식과 동시에 실행하지 않습니다.


검사 시작 사이의 목표 간격입니다. OCR 시간을 포함하며, 오래 걸리면 완료 후 최소 50ms 뒤 다음 검사로 이어집니다. 중복 실행은 하지 않습니다. 낮추면 반복 연산·전력 사용이 늘어납니다.


2·4개는 전체·확대 구역을 큐로 나눕니다. 워커별 엔진 메모리가 추가되며 단일 영역은 1개만 사용합니다. 변경은 현재 작업 후 적용됩니다.


전체 · 확대 분리 검사




자동은 전체 인식 후 불확실 코드·코드 일부가 읽힌 위치를 검사합니다. 코드를 찾지 못하면 선택 구역을 모두 검사합니다. 문자 후보조차 놓친 부분은 생략될 수 있으므로 누락이 의심되면 전체 구역 검사를 사용하세요.










보정은 한 번만 수행합니다. 겹치는 구역을 최대 2배로 확대해 추가 검사하므로 시간이 더 걸립니다. 사진 확대 상태에서는 보이는 영역을 기준으로 분리합니다.

해상도·미리보기 품질



낮추면 보정·OCR 픽셀이 줄지만 작은 글자가 누락될 수 있습니다. 원본보다 키우지 않습니다.
이미지를 준비하면 입력 크기를 표시합니다.


촬영 후 해상도와 별개입니다. 낮추면 실시간 검사가 가벼워지지만 작은 코드 감지가 줄 수 있습니다.


보정을 이 크기 이하에서 수행한 뒤 OCR 설정 크기로 맞춥니다. 높은 OCR 해상도로 되돌려도 축소한 세부 정보가 복구되지는 않습니다. 필터를 모두 끄면 원본 픽셀을 유지합니다.


표시용 보정에만 적용합니다. OCR 입력과 별개이며 높이면 화면 갱신 비용이 늘어납니다.











단계입력 px발견시간

총 시간은 인식 버튼부터 결과 표시까지의 경과 시간입니다. 각 영역 시간은 자르기·OCR·좌표 변환을 포함하며 병렬로 겹칠 수 있어 합산하지 않습니다.


설정은 카메라·사진·테스트에 공통 적용되고 자동 저장됩니다. SIMD는 라이브러리가 지원 여부를 판단하며, OCR 워커 병렬 처리는 WASM 내부 스레드와 별개입니다.
